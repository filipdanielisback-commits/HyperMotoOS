# HyperMoto system extensions

This area is reserved for Android system-extension integration that belongs in the ROM itself, rather than a separately installed launcher.

Potential work includes framework resource overlays, SystemUI integration, setup experience, Settings integration, and system defaults. Implementations must follow the selected Android base's build conventions and permission model.

No platform code exists here yet. Do not claim a feature is implemented until it is integrated into a reproducible ROM build and tested on target hardware.
