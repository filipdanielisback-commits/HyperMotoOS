# HyperMoto visual design

This folder is for original HyperMoto design tokens, mockups, and licensed assets.

Planned direction:
- Translucent layered surfaces with restrained blur and depth.
- High-contrast readable text and accessible controls.
- Rounded icon containers and coherent light/dark themes.
- Original mascot and app artwork; do not copy Apple system assets or Pokémon character artwork.
- Motion that respects reduced-motion and accessibility settings.

Keep source files editable and record the origin and license for every external asset.
