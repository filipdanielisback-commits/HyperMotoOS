# HyperMoto Android packages

Planned independent Android application modules:

- `HyperMotoLauncher` — home screen, dock, app drawer/library, widgets.
- `HyperMotoSettings` — HyperMoto preferences and theme controls.
- `HyperMotoControlCenter` — prototype until platform permissions and SystemUI integration are designed.
- `HyperMotoSetup` — first-boot onboarding using supported Android setup APIs.
- `HyperMotoKeyboard` — privacy-first input method that does not collect typed text.
- `HyperMotoIcons` — original icon resources and themed-icon support.

No modules are implemented yet. Add each with its own Gradle configuration, package name, tests, and license headers.
